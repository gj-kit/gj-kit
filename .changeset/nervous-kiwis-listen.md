Add the first native Expo Health bridge: import and incrementally sync workouts and routes from
HealthKit / Health Connect, write and delete idempotent app-owned workouts, and read heart-rate
samples and step totals. The package includes typed config-plugin props, a peer-free core protocol,
an in-memory native fake for consumer tests, Node/web-safe unavailable fallbacks, native source, and
packed Expo SDK 56/57 consumer checks.
